# FamilyPDF 需求完成稽核

更新日期：2026-07-29

## 非 OCR 功能

| 原始需求 | 狀態 | 驗證證據 |
|---|---|---|
| 接近 PDF-XChange 的家庭常用功能 | 已完成目前家庭版範圍 | 採成熟開源 PDF4QT 基底；具閱讀、搜尋、註解、頁面整理、書籤及安全儲存。這不是商業版 PDF-XChange 的逐功能複製。 |
| 繁體／簡體中文 Windows 安裝使用 | 已完成自動驗證 | Inno Setup 含繁中、簡中、英文；兩種中文安裝流程 exit code `0`，兩套翻譯檔存在，中文檔名由安裝版程式成功開啟。 |
| 不同顏色劃線、框選、打字、標註 | 已完成 | Highlight、Underline、StrikeOut、Square、FreeText、Text 六種標準註解由 FamilyPDF 重開，並由 pypdf 獨立讀回 subtype、顏色及文字內容。 |
| 加入／拆分 PDF | 已完成 | PageMaster 可輸出合併文件或多個分割文件；單數、雙數、`10-20` 範圍分別驗證為 29、29、11 頁。 |
| 數百頁大檔 | 已完成目前基準 | 1,160 頁 PDF 由安裝版 Viewer／Editor 載入 15 秒後皆為 Responding；採頁面快取而非一次渲染全檔。 |
| 書籤 | 已完成 | 本機快速書籤支援彩色文字與資料夾；標準 PDF outline 支援新增可收合資料夾、改文字顏色、階層與頁面目的地，存檔後可由其他閱讀器保留。 |
| 放大縮小、縮圖、跳頁 | 已完成 | Viewer／Editor 有百分比縮放、放大／縮小、符合頁面／寬／高；側欄縮圖可同步目前頁；頁碼欄可直接跳頁。 |
| 同時開啟多份 PDF | 已完成 | Viewer／Editor 具文件分頁及工作階段還原；安裝版多文件啟動回歸與 Viewer／Editor／PageMaster 並行 smoke test 通過。 |
| 缺少套件自動處理 | 已完成建置與 OCR 模型路徑 | 建置腳本會安裝／檢查工具鏈；可攜版內含 Qt、VC runtime 及必要 DLL；OCR 語言缺檔由外掛下載腳本補齊並驗證後原子替換。 |

## OCR 外掛

- 基礎閱讀器與 OCR 分開安裝。
- `eng`、`chi_tra`、`chi_sim` 已內建並完成可搜尋 PDF 文字層端對端驗證。
- `chi_tra_vert`、`chi_sim_vert` 已納入安全自動下載，但目前本機受網路沙盒阻擋，尚待實際下載及直排辨識回歸。
- OCR 外掛是下一階段唯一剩餘工作；非 OCR 家庭版功能已完成上述自動驗證。

## 驗證邊界

- 自動測試證明安裝流程、檔案互通、頁數、標準物件及程式存活；不等同於在兩台實際不同語系 Windows 上完成長時間人工操作。
- PDF-XChange 包含大量商業進階功能；FamilyPDF 的「相近」是指本表列出的家庭常用核心功能。
