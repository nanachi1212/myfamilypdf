## OCR 外掛

- 基礎閱讀器與 OCR 仍可分開安裝；另提供預設一次裝齊、可取消 OCR 的完整安裝程式。
- OCR 外掛版本為 0.3.0；`eng`、`chi_tra`、`chi_sim`、`chi_tra_vert`、`chi_sim_vert` 五個模型已內建。固定繁簡中圖像回歸、封裝後流程及最新安裝後流程均驗證來源雜湊、頁數、可搜尋 PDF 中文字元及 UTF-8 文字輸出。
- 使用者指定的語言缺檔時，OCR 主流程會自動執行官方下載、最多三次重試、檔案大小檢查、Tesseract 實際載入驗證及原子替換；斷線不留下半檔或錯誤輸出 PDF。
- `chi_tra_vert`、`chi_sim_vert` 已由官方來源下載，檔案大小、SHA-256、Tesseract 實際載入及直排模型辨識回歸均通過。
- 橫排與直排繁／簡中文模型、官方下載、缺檔修復及封裝後辨識回歸均已完成；仍保留兩種 Windows 中文系統的長時間人工巡覽邊界。

## 驗證邊界

- 自動測試證明安裝流程、檔案互通、頁數、標準物件及程式存活；不等同於在兩台實際不同語系 Windows 上完成長時間人工操作。
- 最新重建安裝檔編譯成功，隔離靜默安裝 exit code `0`，安裝後五語言 manifest 與 OCR 回歸通過。
- 最新完整驗證安裝檔同時驗證完整與精簡安裝；完整模式包含五個 OCR 模型並通過繁簡中可搜尋 PDF，精簡模式不含 OCR。
- 安裝器內容不是只檢查檔名：完整模式 406 個核心檔案及 29 個 OCR 檔案、精簡模式 406 個核心檔案，已逐檔與可攜包比對 SHA-256。
- PDF-XChange 包含大量商業進階功能；FamilyPDF 的「相近」是指本表列出的家庭常用核心功能。
- Office Export 現在會依垂直順序重建常見的等寬／不等寬雙欄、全寬文字區塊及非重疊 raster 圖片；圖片以 144 DPI 頁面渲染裁成 PNG，欄內圖片限制在對應欄寬，跨欄圖片限制在頁面可用寬度。向量圖形、透明遮罩的精確重建、文字環繞／重疊浮動物件、三欄以上、跨頁表格或精確座標版面仍未支援。
- 文件比較固定 fixture 覆蓋可搜尋文字替換與 GUI 啟動；複雜透明混合、DRM／密碼文件及大型工程圖仍需依實際文件判斷比較品質。

- 本次實際修復 Python 3.14 虛擬環境後，依賴完整性、DOCX／XLSX helper、Microsoft Office smoke 與最終回歸均通過。
- OCR 五種語言模型、Qt／CMake／MSVC／vcpkg 建置鏈和所有 PowerShell QA 腳本也已重新稽核，未發現其他待修復的套件或 DLL 缺失。
- C++ 測試與正式可攜包都不再執行 Qt 6.9.1 會偶發 `0xC0000409` 的 `windeployqt`；改由 PE import 實際依賴整理的 10 個 release Qt DLL 與 15 個外掛固定複製。專用封裝契約、CTest 6/6、完整回歸及完整／精簡隔離安裝均無 Qt 環境警告或 fallback。
