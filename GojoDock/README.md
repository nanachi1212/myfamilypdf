# 悟醬快捷（GojoDock）

平常只是一顆小小的五條悟頭像貼在螢幕邊，點一下展開功能面板，一鍵打開 Google 翻譯、Gmail、Google 地圖、計算機，或任何你自己加的 App／網址。

| 平台 | 做法 | 懸浮頭像 |
| --- | --- | --- |
| Android（Galaxy S23 Ultra） | 本資料夾的 App | 有：可拖曳、自動貼邊、閒置半透明收進側邊 |
| iOS（iPhone 17 Pro） | 系統內建「動作按鈕」＋「捷徑」，見下方 | 沒有：iOS 不允許 App 浮在其他 App 上面 |

## Android：安裝

1. 到 GitHub 的 **Actions → GojoDock Android**，點最新一次成功的執行，在最下面 **Artifacts** 下載 `GojoDock-apk`，解壓縮得到 `app-debug.apk`。
2. S23 Ultra 若開著「自動封鎖程式」會擋住安裝：**設定 → 安全性與隱私 → 自動封鎖程式 → 關閉**（裝完可再打開）。
3. 點 `app-debug.apk` 安裝；跳出「安裝未知應用程式」就允許，Play 保護機制警告選「仍要安裝」。
4. 打開「悟醬快捷」，依畫面完成：
   - **允許顯示在其他應用程式上層**（必要）
   - **允許通知**（建議，通知列可一鍵收起頭像）
   - **電池設為「不受限制」**（建議，避免 One UI 省電把頭像關掉）

## Android：使用

- **點頭像**：展開功能面板；點空白處、再點頭像或返回手勢：收起。
- **按住拖曳**：移動位置，放開自動貼到左／右邊；2.5 秒沒碰會半透明並藏一半到邊緣。
- **新增／刪除功能**：面板裡的「＋ 新增」或「編輯」，或直接打開 App。可加任何已安裝的 App 或網址，可改名、調整順序、移除。
- **外觀**：頭像可選「雙眼笑」「掀眼罩」或相簿裡任一張圖；可調大小（32–64 dp）、閒置透明度、是否自動收邊、開機自動出現。

S23 Ultra 適配：避開頂部打孔鏡頭與狀態列、底部手勢列；橫向、改解析度（FHD+／WQHD+）、深色模式都會自動調整。Samsung 側邊面板把手預設在右邊，若擋到可把頭像拖到左邊。

## iOS（iPhone 17 Pro）：長按「動作按鈕」叫出選單

iPhone 不允許一般 App 畫在其他 App 上面，所以做不出懸浮頭像；右側電源鍵長按也只能叫 Siri。最接近的做法是機身**左側的「動作按鈕」**（iPhone 15 Pro 以後才有），長按就跑一個捷徑，跳出功能選單：

1. 打開「捷徑」App → 右上「＋」→ 名稱取「悟の快捷」。
2. 加入動作「**從選單中選擇**」（Choose from Menu），選項打：`Google 翻譯`、`Gmail`、`Google 地圖`、`計算機`。
3. 在每個選項底下加入「**打開 App**」（Open App），選對應的 App。
4. **設定 → 動作按鈕** → 滑到「捷徑」→ 選「悟の快捷」。
5. 之後長按左側動作按鈕就會跳出選單。要新增／刪除功能：編輯這個捷徑，加減選項並各配一個「打開 App」。

想要螢幕上有一顆可拖曳的浮動按鈕：用系統的「**輔助觸控**」（AssistiveTouch）。

1. 在「捷徑」App 為每個 App 各建一個只有「打開 App」的捷徑（例如「翻譯」「Gmail」「地圖」「計算機」）。
2. **設定 → 輔助使用 → 觸控 → 輔助觸控** → 打開。
3. **自訂最上層選單**：用 －／＋ 調成想要的數量（1–8 個），點每個圖示改成剛建的捷徑。
4. **閒置時透明度** 調低，按鈕就不擋畫面；拖曳後會自動貼邊。

限制：輔助觸控按鈕的外觀不能換成五條悟。想看到悟醬，可在「捷徑」App 長按「悟の快捷」→ **加入主畫面**，圖示選這張頭像（`app/src/main/res/drawable-nodpi/head_smile.png`，或你原本的圖）。

## 給開發者

- 純 Kotlin、無第三方套件；`minSdk 31`、`targetSdk 35`。
- 建置：`./gradlew assembleDebug`（需 JDK 17 與 Android SDK）。
- CI：`.github/workflows/gojodock-android.yml` 建置、lint，並在 1080×2316／450 dpi 的 Android 15 模擬器上做冒煙測試，截圖放在 `GojoDock-smoke` artifact。
- 頭像圖片為使用者提供的同人圖裁切，僅供個人使用，請勿上架。
